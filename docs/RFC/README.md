# RFC（Request for Comments）

## 什么是 RFC？

RFC（征求意见稿）是 NordHjem 前端项目中用于提出和讨论**重要技术决策**的标准化文档格式。

当一个变更涉及以下任一情形时，必须先提交 RFC，由 Owner 批准后才能开始实施：

- 影响多个模块的架构调整
- 引入新的技术依赖或框架
- 变更核心数据流或状态管理方案
- 性能优化方案（影响 Core Web Vitals SLO）
- 破坏性 API 接口变更
- 部署基础设施调整（Vercel 配置、CDN、环境变量）

## 使用方式

1. 复制 RFC 模板（见下方）创建新文件，命名格式：`RFC-[编号]-[简短标题].md`
   - 例：`RFC-001-replace-state-management.md`
2. 填写模板中所有必填项
3. 创建 PR，请求 Owner 评审
4. Owner 在 PR 上 Approve = RFC 批准，可以开始实施
5. 实施完成后更新 RFC 状态为 `Approved`，记录最终实施情况
